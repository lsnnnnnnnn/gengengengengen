# 论文图表样式

配色依据用户提供的参考图，采用图中印刷的 HEX 值；图中个别 RGB 数字与 HEX 不一致时，以 HEX 为准。

| 色名 | HEX | 固定用途 |
|---|---|---|
| 淡紫 | `#B6B3D6` | B06_MATCHED，虚线、方点 |
| 浅丁香 | `#CFCCE3` | 共同节点信息 |
| 雾灰紫 | `#D5D3DE` | 共同自身分支 |
| 暖灰 | `#D5D1D1` | 辅助对照 |
| 浅桃 | `#F6DFD6` | 共同协议背景 |
| 鲑粉 | `#F8B2A2` | B13，点划线、三角点；逐边分支 |
| 珊瑚 | `#F1837A` | 附加消融 |
| 玫瑰 | `#E9687A` | M01_FULL，实线、圆点 |

`thesispalette.sty` 提供 LaTeX 颜色名；`palette.json` 提供跨绘图库的模型样式映射；`thesis.mplstyle` 提供 Matplotlib 基础样式，可通过 `plt.style.use(...)` 载入。模型命名的颜色、线型和标记应显式取自 JSON，不能让绘图顺序决定模型颜色。

使用白底、深色文字。浅色适合面填充，曲线同时使用足够线宽、线型和标记。置信区间可使用同色透明填充；显著性须提供数值或明确符号，不能只靠颜色。坐标轴写明单位、期限和损失定义。不同模型保持同一评价域，网络图保持同一节点布局与边尺度。

`matched_architecture.tex` 是纯方法示意图，未使用市场数据。实证图只能读取经确认的实际输出；缺少输出时保留待填状态，不能将空值画为零或模拟预测改善。
